At this point, your pganalyze setup should be ready to collect EXPLAIN plans, as long as
the role your application connects as has the `auto_explain` settings from Step 3 applied,
and [Log Insights](/docs/log-insights/setup/supabase/01_set_up_log_drain) is set up and
receiving log data. Since you may not have any slow queries in your system right now, we
can generate a synthetic slow query that we can use to confirm everything is working.

The collector includes a flag to do this for you automatically, based on your
`auto_explain.log_min_duration`:

```bash
sudo pganalyze-collector --test-explain
```

This will produce no output but will run an artificially slow query using the
Postgres `pg_sleep` function.
