## Check if auto_explain is already enabled

First, to check if `auto_explain` is already enabled, run the following using a superuser SQL
prompt (for example, via `kubectl cnpg psql my-cluster`):

```sql
SELECT setting, pending_restart FROM pg_settings WHERE name = 'shared_preload_libraries';
```

If `auto_explain` is included in the `shared_preload_libraries` value and `pending_restart`
is false, the module is already enabled.
